# KHZ

A lightweight, static, multilingual editorial site focused on systems, verification, privacy, and accountable technology.

## Structure
- `index.html` — home page and article index
- `article.html` — article template
- `app.js` — home-page translations and card metadata
- `article.js` — editorial content in English, Arabic, and Chinese
- `styles.css` — responsive styling and reduced-motion support

## Editorial approach
The site distinguishes observation, sourced reporting, inference, and unknowns. It avoids personal attacks and does not present unverified allegations as fact.

## Reference frameworks
- NIST AI RMF 1.0
- OECD AI Principles
- European Union AI Act, Article 50 transparency obligations
- Saudi Personal Data Protection Law guidance for controllers and processors

## Accessibility and performance
- Semantic HTML and keyboard skip link
- Responsive layout
- RTL support for Arabic
- `prefers-reduced-motion` support
- No external trackers, fonts, images, or build step required
